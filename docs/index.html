▸Coding-solo recipe I left running (2026-08-17)

Bakeer's flags on the house image. Voice off. Wrapper: scripts/boot-bakeer-dspark.sh.

docker run -d --name qwen38-dspark-vllm --gpus all --ipc=host --net=host \
  -e VLLM_MARLIN_USE_ATOMIC_ADD=1 \
  -v ~/.cache/huggingface:/root/.cache/huggingface \
  -v ~/vllm-cache:/root/.cache/vllm \
  --entrypoint vllm spark-vllm:qwen38 \
  serve unsloth/Qwen3.8-27B-NVFP4 \
  --served-model-name unsloth27b qwen3.8-27b \
  --host 0.0.0.0 --port 8888 \
  --max-model-len 262144 --gpu-memory-utilization 0.85 \
  --max-num-batched-tokens 16384 --enable-prefix-caching \
  --reasoning-parser qwen3 --tool-call-parser qwen3_xml \
  --enable-auto-tool-choice \
  --limit-mm-per-prompt.image 2 --limit-mm-per-prompt.video 0 \
  --speculative-config '{"method":"dspark","model":"Doopeworld/Qwen3.8-27B-DSpark-vLLM","num_speculative_tokens":14,"draft_sample_method":"probabilistic"}'

KV: 1,161,326 tokens · 4.43× @262k. Live talk stays SGLang 0.55 + voice. House ceiling remains 0.80 when ASR/TTS or Comfy share the box.
