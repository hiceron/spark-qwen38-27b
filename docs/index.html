The short version
  • Native MTP is the daily driver. k=3 is a hair faster and a hair less KV. I keep k=2.
  • Raising gpu-memory-utilization 0.55 → 0.74 is the working KV lever. NVFP4-KV is blocked by the same triton_attn backend that makes FP8 KV work on GB10.
  • RadixArk's DSpark is real. On Unsloth NVFP4 + vLLM it dies in get_draft_quant_config. Their card is SGLang + official FP8.
  • Nobody has published a z-lab Qwen3.8-27B-DFlash.
  • This bench streams chat with thinking on. keys' 31.7 and Wesche's 23.7 use different tools. I am replaying both; those decimals are not mine yet.

▸Daily recipe I left running

Image is a one-line fork of eugr/spark-vllm with ffmpeg 6.1.1. Stock eugr boots the text path.

export CUTE_DSL_ARCH=sm_121a
docker run -d --name unsloth38-27b --gpus all --ipc=host --net=host \
  -e CUTE_DSL_ARCH=sm_121a \
  -v ~/.cache/huggingface:/root/.cache/huggingface \
  -v ~/vllm-cache:/root/.cache/vllm \
  --entrypoint vllm spark-vllm:qwen38 \
  serve unsloth/Qwen3.8-27B-NVFP4 \
  --served-model-name unsloth27b \
  --host 0.0.0.0 --port 8888 --trust-remote-code \
  --quantization compressed-tensors \
  --attention-backend triton_attn \
  --gpu-memory-utilization 0.74 --max-model-len 262144 \
  --max-num-seqs 4 --max-num-batched-tokens 32768 \
  --enable-chunked-prefill --async-scheduling --enable-prefix-caching \
  --skip-mm-profiling \
  --speculative-config '{"method":"mtp","num_speculative_tokens":2}' \
  --reasoning-parser qwen3 --tool-call-parser qwen3_coder \
  --enable-auto-tool-choice --hf-overrides '{}'

triton_attn is required for FP8 KV on sm_121. Voice coexist stays at U=0.55. House ceiling remains 0.80 — speculation scratch sits outside that fraction.

02Util is the KV lever. NVFP4-KV is not.

ValueError: Selected backend AttentionBackendEnum.TRITON_ATTN

03DSpark exists. It does not boot here.

RadixArk/Qwen3.8-27B-DSpark is a 1.36B BF16 draft, trained with SpecForge, written for official FP8 + SGLang. I pointed vLLM at it anyway. Engine resolved DSparkDraftModel, started both weights, then:

File vllm/model_executor/models/utils.py get_draft_quant_config
ValueError: hf_overrides must be a dict for get_quant_config

Passing --hf-overrides '{}' on the target does not fix the draft ModelConfig. No tok/s — it never served a token. There is no z-lab/Qwen3.8-27B-DFlash; the question is already on the official card.

House ceiling

keys' champion uses --gpu-memory-utilization 0.90. On unified memory that fraction is also the OS. I will not run 0.90 next to voice or ComfyUI. Replay happens on a cleared box, or at 0.80 first.
